- 首次提交 80 个文件（86.2 MB），含 7 份调研 md、`docs/可行性方案.md`、`app/libs/sherpa-onnx.aar`（47 MB）、`assets/{asr,kws,l2d/*.js}`。

**为什么 `.local_assets/` 要单独存在**
`live2d.7z` 里的大肥鱼模型 `.vtube.json` 写着 `"WorkshopSharingForbidden": true`，包内零许可文本。放进 `assets/` 就会被打进 APK 并随源码库分发。所以模型统一放在被 ignore 的 `.local_assets/`，App 在运行时从用户导入的目录读（对应决策 D1）。`assets/l2d/` 只保留三个 JS 运行库（pixi / cubism4 / cubismcore），它们可再分发。

**验证**
- `git log --oneline` → `b43793a p0-1 初始化仓库，纳入方案与调研文档`
- `git ls-files | grep -c "l2d/model"` → `0`（模型未入索引，符合预期）

**结果**：✅ 仓库可 diff、可回退；后续每步一提交。

**偏离**：无。
